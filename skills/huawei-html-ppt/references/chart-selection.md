# 报告优先使用简单图表

先明确本页要说明什么，再选择一眼能看懂的表达。图表种类多不代表报告更好；默认优先简单曲线、柱状图、对比表和必要的结构图、流程图。

不使用饼图或环图；占比、资源构成用简洁分项表或条形图表达。

## 默认选择

| 要说明什么 | 优先选择 |
|---|---|
| 趋势随变量变化 | 少量曲线或折线，直接标注关键点 |
| 数值大小与方案差异 | 柱状图、条形图或简短对比表 |
| 资源构成与耗时项 | 简单分项表或并列条形图 |
| 配置、目标、结果与状态 | 对比表、目标/结果表、简洁里程碑 |
| 模块关系与执行机制 | 清楚的结构图、流程图或局部放大 |

根据数据和用途变通，不强制套流程图，也不为了展示图表种类而增加复杂图。

## 复杂图的使用边界

堆叠图、分解图、热力图、散点图、时序图，以及多维、多轴、密集曲线等，不作为报告正文的默认选择。优先考虑能否用简单曲线、柱状图、表格或简化结构图说明同一问题。

确实无法替代，且简化后仍容易理解时才使用；控制系列、变量和标注数量。详细分布、复杂时序与敏感性分析通常放在附录或分析底稿，正文只保留关键发现。用户明确需要某种图时按需求处理。

## 数据与表达

- 从结构化数据生成图；坐标、单位和必要条件完整。
- 理论估算、仿真与实测要区分。数据点少时不补造平滑曲线或外推结果。
- 比较条件不同的结果分开呈现或标清；避免让双轴、截断坐标和过多系列增加理解负担。
- 图服务于本页结论；没有必要的图就直接用表格或文字。
- 继续使用黑灰红文字和克制的图形配色；来源与推导放隐藏备注。
- 保留可编辑数据或矢量源文件，保持报告页紧凑清楚。
