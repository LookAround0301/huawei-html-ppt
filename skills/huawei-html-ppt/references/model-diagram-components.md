# 已验证的技术图元与组合

源文件：[technical-stencil.drawio](../assets/diagram-components/technical-stencil.drawio)。配色令牌：[palette.css](../assets/diagram-components/palette.css)。均可本地使用，不依赖在线导出。

| 图元/组合 | 用途与接口 | 使用边界 |
|---|---|---|
| 文字输入 / 输出 | 直接标注 Input、Output、h、Q 等，按需附真实维度 | 不用矩阵网格装饰输入输出 |
| 张量布局 / 矩阵 | 仅在解释分片、缓存布局或数据排列时使用 | 格数是示意，不把可见格数当真实规模 |
| 矩形状态框 | 持久状态、缓存；读/写和更新独立标注 | 不用圆饼状柱体；固定大小状态与随历史增长 KV 不能混画 |
| 投影与控制节点 | 投影/算子用圆角矩形，条件用菱形，求和用圆圈 | 形状语义保持稳定，不把分组用箭头串联 |
| 专家扇出/汇聚 | Router、多个专家、加权合并；实线数据，虚线控制 | 共享分支与路由分支区分，规范化位置按实际 forward |
| 卡 / die / rank 容器 | 物理卡嵌套可见设备；容量和编号在具体场景标注 | 物理卡数与 world size、TP/PP/EP 关系不得想当然 |
| P/D 并行与状态迁移 | 按阶段画流水/泳道，显式列传输对象 | 示意拓扑不代表真实节点数或已实现性能 |

上述组件是通用表达。每次使用仍需按当前源码核对拓扑，分别验证 SVG 预览和可编辑源图。
