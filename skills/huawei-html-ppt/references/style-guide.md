# 华为技术报告 PPT 风格规范（从模板与实际汇报 PPT 提取）

来源：`华为风格PPT模板.pptx`（官方模板）+ `推理技术项目汇报三期.pptx`（85 页实际汇报）。
画布 13.34in × 7.5in（16:9），HTML 中映射为 1280 × 720 px（1in ≈ 96px）。

## 1. 颜色（色卡纪律）

**唯一彩色来源 = 模板第 4 页"图表配色示意"色卡**（提取自 `ppt/charts/chart1.xml`，
与用户截图一致）：除照片/截图等图片资产外，**一切元素只允许使用下列 6 色 +
黑白灰中性色**。蓝/绿/青等卡外色一律退役，不允许任何"花里胡哨"的颜色。

### 色卡 6 色（图表系列顺序 = 模板图卡从左到右）

| 色值 | 名称 | 语义 |
|---|---|---|
| `#C5C5C5` | 浅灰 | 基线系列、层带浅底、表格细边框 |
| `#929292` | 中灰 | 次要图表系列、弱化文字 |
| `#666666` | 深灰 | 次要文字、页脚、基线/对比文字 |
| `#E9002F` | 亮红 | 华为红：封面角标、图形点缀、图表高亮系列 |
| `#C00000` | 深红 | 页标题、关键数字、当前章、红标签、**正向/关键状态文字**、P0/核心标记 |
| `#FBA000` | 琥珀 | 警示/注意/中优先级（**只作色块、圆点、图表系列，不作小字文字色**） |

### 中性色（黑白灰，模板 theme1）

正文近黑 `#1D1D1A`（dk1）；目录页底 `#EBEBEB`；内容灰底块 `#F2F2F2`；
白底 `#FFFFFF`；色卡同系浅底：红 12% tint `#FCE0E6`（热点/关键路径节点）、
琥珀 12% tint `#FDEED2`（量化/注意节点）。

### 语义映射（原蓝绿橙黄的替代）

- 正向/完成/我方/关键路径 → **红**（`#C00000` 文字、`#FCE0E6` 底、"我方"系列 `#E9002F`）
- 警示/注意/中优先级 → **琥珀**（色块 `#FBA000`、浅底 `#FDEED2`；小字警示用红文字）
- 基线/对方/次要 → **灰阶**（`#666666` 文字、`#C5C5C5`/`#929292` 图表系列）
- **标签块竖排标签一律红色** `#C00000`（用户明确反馈：灰标签怪，统一红；
  "挑战/使用约束"类块也不例外，区分靠标签文字不靠颜色）
- 流程节点：默认 `#F2F2F2` 灰面；关键/热点节点 `#FCE0E6` 红浅底；注意节点 `#FDEED2` 琥珀浅底；全部黑边
- 优先级/分级：P0=红 `#C00000`，P1=琥珀 `#FBA000`（或红浅底），P2=深灰 `#666666`

CSS 里旧变量名（`--hw-blue/--hw-green/--hw-orange/--hw-node-*` 等）保留为
兼容别名、色值已并入色卡，旧页面自动合规；**新页面一律用规范名**。

## 2. 字体

- 中文：微软雅黑（Microsoft YaHei），全文一种字体，靠字重和字号分层。
- 西文/数字：Arial（正文）、Arial Black（封面主题字体）。
- 代码/版本号：Consolas。
- 字号体系（PPT pt → HTML px）：
  - 封面标题 32pt → 44px 加粗
  - 内容页标题 22pt → 30px 加粗红色
  - 模块/卡片标题 15pt → 20px 加粗
  - 正文 12pt → 16px；次要 10.5pt → 14px；脚注 9pt → 12px
- 实际汇报页正文以 10.5–12pt 为主，信息密度很高，一页可容纳 2 个图表 + 多段文字。

## 3. 页面类型与版式

### 版面通用原则：结论先行（适用于一切页面与一切组件）
- 页面叙事顺序固定为 **判断/导读 → 证据/明细 → 注脚** 三段：
  1. **页首**（标题正下方）：一切"先告诉读者重点"的元素——要点/结论/
     分析结论/使用约束等标签块、KPI 摘要条、关键数字、口径与图例说明；
  2. **页中**：数据明细表、架构图/示意图、流程图、推导过程等证据本体；
  3. **页尾**：仅来源/口径/假设类脚注与补充说明，**不放任何判断性内容**。
- **标签块位置铁律**（用户明确反馈）：标签块**永远放在内容区上方**
  （标题正下方、表格/图/卡片之前），**禁止放在内容之后或页底**——
  "使用约束/部署建议"这类块也是判断性内容，同样上置；
  且与下方内容**保持 ≥20px 间距**（`.label-blocks` 默认 margin-bottom:20px），
  禁止贴死（不要用 margin-bottom:0 抵消）。
- 原则高于组件清单：现有组件照此归位，未来新增任何元素（卡片、图、块、
  表）也按此归位——判断性内容绝不放页底（用户多轮反馈的核心诉求）。
- 标题本身也是一环：标题即结论（含量化数字），页首标签块是标题的展开，
  二者合起来让读者不看完页也能带走判断。

### 封面（探索版式）
- 上部 81.6%（588px）为全宽风光照片（雪山/滑翔伞，冷色调 + 一点红色点缀）。
- 主标题位于左上 (94px, 118px)，黑色加粗。
- 红色 L 形角标装饰在照片中部偏右。
- 中下部三行元信息：`部门：…`、`作者：…`、`日期：…`，加粗黑字。
- 底部白条：左下 `Security Level:` 小灰字，右下 HUAWEI 红花 logo（高约 44px）。

### 目录页
- 浅灰底 `#EBEBEB`。
- 左上"目录"40px 加粗黑字，下方 78×4px 红色短线。
- 条目为编号列表（1. 2. 3. 4.），26px；当前章节红色 32px 加粗。
- 用于章节间过渡：重复出现并在每个章节开始前高亮对应条目。

### 摘要页（参考 `DeepSeek V4.1模型分析.pptx` 实际页）
- 版式 = 结论式红标题 + **一个**通栏"分析结论"标签块 + **双卡片**（图 + 参数对比表）。
- "分析结论"标签块：单个 `.label-block` 通栏（不用 blue 变体），竖排红标签
  + `#F2F2F2` 灰底面板，内放 4 条左右 `➢` 要点；正文近黑 14px，关键词加粗，
  关键数字红色。
  **高度必须压在整页 1/4（最多 1/3）以内** —— 明确反馈：结论块过大显 AI 味。
- 主体用双卡片撑满，不留空白：
  - 左"架构概览"卡片：**优先用官方/现成的模型结构图**——报告配套 PPTX 的
    内嵌媒体里常有（PPTX=OPC zip，用 python `zipfile` 列出 `ppt/media/*`
    按 `PIL` 看尺寸挑 candidate；开发期复制进 `ppt_assets/` 后 `<img>` 引入，
    单文件交付时改为 base64 内嵌；显示高度 ~385px 时原图 1142px 高的图
    文字仍可读）。无现成图时**用 draw.io 画**（见
    [drawio-diagram.md](drawio-diagram.md)：浏览器实时预览迭代，横向版，
    交付 .drawio + 按 XML 坐标转等价内联 SVG 嵌入）。手绘内联 SVG
    （层带/通路/链路/chips，直角矩形+黑边，模板节点色）是最后兜底。
  - 右"参数对比"卡片：**3 列 `维度 | 本模型 | 对方`**（备注列用户明确删过；
    补充说明放分析结论要点里），行少时 `table.hw.compact` 并用
    `height:calc(100% - 10px)` 拉伸行高填满卡片，行多时 `table.hw.tight`。
    对比维度用模型卡标准清单（用户指定"模型对比分析就
    关注这些"）：总参数量、层数、最长上下文、ViT 大小、Engram、Q LoRA rank、
    index_n_heads、隐藏层维度、路由专家隐藏层维度、激活函数、共享专家数、
    路由专家数、激活专家数、Compressor ratio。
  - **不放独立关键指标条** —— 对比表在场时指标条冗余（用户明确删除过）。
- **禁用**：非红标签块（灰/蓝一律不用，见标签颜色铁律）、KPI 大数字卡片、
  渐变/圆角彩卡 —— 摘要页出现这些即"AI 味"，实际华为页从不这样排。

### 内容页（实际 PPT 均基于章节页版式）
- 页标题：左上 (37px, 30px)，红色 `#C00000` 加粗 30px；
  标题常用【标签】前缀，如 `【长序列】细粒度并发调度：…`，结论式标题
  （标题即结论，含量化数字，如"系统吞吐提升10%+，精度损失<0.5%"）。
- 右上角：章节导航面包屑（小表格样式，斜体加粗 11px，当前项红底白字）。
- 标题下方常放 2 个并排"标签块"：左侧 44px 宽**红色**竖排标签（目标/挑战/
  进展等，一律红），右侧 `#F2F2F2` 灰底内容面板，内放 2–4 条要点
  （归位见上方通用原则）。
- 主体区域：2–3 栏卡片/图表混排；卡片为黑色或 2.5px 红色边框围栏，
  顶部中央骑线放模块标题（如"关键技术""技术进展"）。
- 表格（规格从模板 PPT XML 实抄，勿自创）：表头 `#F2F2F2` 灰底 + 近黑 `#1D1D1A` 粗体字；表体全白底无斑马纹；边框近黑 `#1D1D1A` 0.5pt 细线；列宽比例照抄原 PPT gridCol。内容字色：类别前缀/责任人/决策建议 `#0000FF` 蓝，【技术点名】 `#C00000` 红加粗，正文近黑。
- 流程图：直角矩形节点（灰面 `#F2F2F2` / 红浅底 `#FCE0E6` / 琥珀浅底 `#FDEED2` +
  黑边）+ 箭头连线，节点内 14px。
- 对比页：标题带 `【对比】` 前缀；结构 = 结论块（页首，通用原则）+
  KPI 数字条（3–4 个，仅此页可用）+ 多行对比表（自己 vs 对方，关键优值
  `td.hl` 红色）+ 口径/来源脚注（tiny 灰字，说明统计口径差异避免误读）。
- 页脚：左下 `Page X/Y` + `Huawei Confidential`（12px 灰），右下 HUAWEI logo（高 22px）。
  **X/Y 全场唯一**（合并/拆页后必须重排序号），页码连续反映实际页序。

### 结束页
- 白底，左侧大号 "Thank you."（Arial，54px），右侧两段愿景文案 + 版权
  说明小字 + logo。

## 4. 内容写作风格

- 结论式标题：标题直接说出结论与量化收益，不用"XX介绍"式标题。
- 强调模式：**关键词加粗** + 关键数字红色（或红色加粗），对比基线用深灰 `#666666`。
- 状态标注：完成/正向用绿色（如 "HCCL 落地迁移中"、"+20.4%"），风险/缺口用橙色或红色。
- 层级符号：实心方块 □ → 数字 ①②③ → 圆点 •，逐层缩小。
- 密度高：一页讲透一个主题，允许文字较多，但必须分区（标签块/卡片/表格）。
- **页面必须撑满**，不留大片底部空白（"留白太多"是明确反馈过的缺点）：
  - `.content-body` 已是 flex `space-evenly`，内容不足一页时自动均匀分布；
  - 单表页用 `table.hw.roomy`（8px 10px 内边距、14px 字号）撑起高度；
  - 图少字少的页加大字号/节点尺寸，而不是原样留白；
  - 反过来，接近满页时不要再加 margin，避免溢出。
- 技术示意图占页面 50%+，文字围绕图组织。

## 5. 反模式（"AI 味"禁用项，均来自实际反馈）

- **摘要页/结论页禁用 KPI 大数字卡片** —— 数字一律进表格，卡片只在对比页少量用。
- **摘要页禁用第二标签块/彩色标签块** —— 摘要只有"分析结论"一个红标签块；
  深灰"挑战"标签仅用于内容页（蓝标签已随色卡纪律退役）。
- 不用渐变、投影卡片、圆角彩卡、emoji 图标、进度环等互联网风格装饰。
- 装饰越少越好：红竖条之类纯装饰已删除，标题就是红色加粗文字本身。
- 装饰性元素必须有信息含义（状态色、热点红浅底路径、红色关键数字）。
