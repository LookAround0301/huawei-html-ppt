# 共享视觉规范

本规范用于技术项目与洞察分析两个分支。具体页首结构由各分支决定，不再要求所有页都“结论条＋双卡片”。

## 画布与层级

逻辑画布1280×720，安全边距约36–42 px，页标题30 px，模块标题20–22 px，正文17–21 px，密集图表标签15–17 px。Microsoft YaHei 为中文主字体，代码可用 Consolas。内容区尽量充分利用，避免大块无意义留白；保留必要的页边距和分组间距。

技术项目页使用挑战＋目标或目标＋进展摘要；洞察页在标题下方固定保留红色“分析结论”标签＋通栏浅灰底结论块，标题中的判断不替代此栏。顶部摘要合计通常不超过画布1/4。主体布局从目录中按内容选择，避免连续多页同样的双栏。

## 配色与图形

连线优先走水平、垂直和直角折线，连接到图形边缘的端口；同一层的端口对齐，减少折返、斜线和无意义拐点。避免穿过标签、节点和分组标题。

输入、输出和普通中间变量直接使用英文文字标注，必要时附维度；不用矩阵网格作装饰图标。只有矩阵布局、分片或数据排列本身是分析对象时，才按实际含义画矩阵。缓存/状态使用简洁矩形并标清名称与读写关系。不使用饼图、环图或圆饼状存储图元。

图内标题、节点、边注、图例、坐标轴和尺寸说明只用英文、标准术语、符号与数值，不出现中文。中文用于图外页面标题、正文、分析结论与备注。优先使用英文原图；只有中文原图时，准确翻译本地副本中的文字并保留原始文件，不能静默删除必要标签。

- 页面标题/关键判断：深红 `#C00000`。正文 `#1D1D1A`，次要文字 `#666666`，表头/摘要底 `#F2F4F6`，框线 `#AEB8C0`。
- 图片和技术图的填充可以采用少量低饱和色区分结构；**图内文字、尺寸、图例与标注仍使用华为黑灰红体系**。正文黑、次要说明灰、关键增量红。不按节点类型给文字轮流上蓝/绿/紫/橙色。
- 参考图已经清楚时，保留其主干方向、分组和连线结构，先准确复用再调整样式；不能用几张并列机制卡片替代完整结构图。
- 成对摘要标签默认使用品牌红。用户指定或严格参考页要求时可使用参考的蓝色第二标签，不把颜色选择误写成全局硬限制。
- 围栏和表格采用细边，骑线标题有白色底托，分组以结构关系为依据。
- 不使用无信息作用的渐变、阴影和彩色装饰卡。矩形算子、必要的张量布局、矩形缓存、设备分组、运算符和通信边组合表达技术结构。

图表类型按实际分析需要选择，见 [chart-selection.md](chart-selection.md)。默认优先简单曲线、柱状图、对比表及清楚的结构图、流程图。堆叠图、热力图、散点图、复杂时序等不常规使用；只有确有必要且容易理解时才放正文。

## 表格

灰表头、白表体、0.7–1 px细线。列宽由字段长短决定，必要时分组/合并；数值保留单位与条件。强调差异而非整列刷色。技术项目表关注目标/结果/状态，洞察表关注变量/机制/代价/边界。

## 输出

页脚只保留页码与品牌信息。来源、引用、解释制作过程的文字只放隐藏元数据或演讲者备注。关键技术条件、未知项、理论/实测性质属于内容而非批注，须正常可见。

使用自包含HTML及自动适应窗口组件；不要按长截图像素固定裁页。逐页检查文字换行、连线穿字、表格截断、窄窗缩放、末页与打印。PPTX按转换规范保留原生对象，并检查演讲者备注。

## 文字：直接、具体，术语用准

标题直接说本页讲什么即可，例如“整体结构”“A3 和 A5 的量化方案与显存占用”“Prefill 和 Decode 的并行配置”。结论放分析结论栏或总进展，不强迫每个标题都写成带判断的长句。

正文先交代对象、动作、结果或问题。有准确术语就用术语，例如 KV Cache、Indexer、TP/EP、量化、时延、显存；不要为了显得专业，额外拼接抽象说法。写“检查量化格式和分片结果”，不写“形成亲和性闭环”；写“还需要测量通信开销”，不写“以验证驱动收益收口”。

不是禁用某个词：如“技术研发协同计划”有明确对象，可以保留；避免的是没有具体含义的套话。条件、数值、技术含义和状态不能因为改写而丢失。长句先拆短，不生造词、不硬凑对仗，也不把所有术语改成不准确的日常话。

## 尽量减少留白

页面要紧凑、好读，图表和正文充分利用可用内容区。逐页检查底部、左右栏及表格周围是否有大块空白。

- 内容少时，先放大主体图、表格和字号，合理增加表格行高，或改成通栏布局。
- 左右内容不均时，调整栏宽与布局，不因套固定模板而让一侧空着。
- 相邻页内容相关且都偏少时，优先合并，减少不必要的页数。
- 图示和表格过大时可以缩小或调整栏宽，以实际投影尺寸可读为准，不能挤掉结论和分析依据。图放大时保持比例和完整结构；不要拉伸图形、堆重复文字、装饰或无关内容来填空。
- 保留必要的边距、图文间距和层次，避免文字拥挤、图内标注过小或连线穿字。

本规则同时适用于技术项目与洞察分析；现有绘图、配色和结论栏规则继续保留。
