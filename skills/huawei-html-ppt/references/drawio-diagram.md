# 本地矢量与 draw.io

默认从同一份 width/height/elements 几何数据输出 SVG 与 draw.io XML。前者嵌入HTML；后者可在用户本地 draw.io 桌面版继续编辑。核心不携带 draw.io 服务、node_modules 或在线编辑器。

使用现有复杂原图时，先检查形状、边、分组、字体及外部图片。不要为套入通用渲染器而删节点或改拓扑。可以保留原文件，通过本地桌面工具导出SVG；无法确认完全本地时不上传。

本模块几何转换支持矩形、椭圆、折线、文本及三角操作节点。更复杂的任意形状应保留原生draw.io，或扩展并验证转换器，不能冒充已保真转换。需要PPTX时另按转换规范处理。

新增最小组件放 `assets/units/`，用局部JSON/SVG表达接口、参数和关系；完整模型图、原始截图、完整报告留在项目目录。目录记录来源页和复用边界。
