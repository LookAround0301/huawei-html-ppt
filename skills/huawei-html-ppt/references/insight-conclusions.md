# 洞察结论：有事实、有解释、能支持判断

用于洞察分析分支。保留既有红色“分析结论”栏和绘图标准，本文件只改进选材与写法。结论是本页最值得读者记住的信息，不能只说“本页介绍了什么”。

## 先理解材料，再形成页面结论

把源码、报告、表格和测试结果合起来读：明确核心变化，沿数据流或执行路径理解机制，再联系算力、访存、缓存、通信与部署约束。提炼当前证据支持的判断后再选图排版，不把字段摘抄或套话润色当成分析。

有多种解释时比较它们各自需要的前提；能得出判断就直接说，缺少关键证据时指出具体缺口。分析底稿可简记“依据、推理、结论、适用条件”，留在本地工作记录，不要求把这四项都塞进每页。

## 按页的问题写，不套一句话模板

| 页面 | 结论应交代什么 | 旁边保留的证据 |
|---|---|---|
| 模型概览 | 主干如何组成、相对基线改在哪里、哪些关键配置影响理解 | 层数/比例、上下文、注意力、MoE、原生权重和Cache格式、特殊层；按相关性选取 |
| 局部机制 | 新增或改变的路径怎样影响计算、访存、缓存或通信；哪些成本仍在 | 前后结构、维度、算式、缓存寿命和作用范围 |
| 性能与瓶颈 | 同口径结果差多少、主要耗时在哪、证据支持哪个原因 | 测试条件、占比/时延/吞吐；只给容量不能证明速度或最优策略 |
| A3/A5部署 | P/D具体并行组合、设备规模、请求条件、最大驻留与推荐起点 | 各平台独立的分项估算、PP最大stage、精度、OS/通信/工作区统计范围 |
| 适配与优化 | 优先改哪个模块、针对什么限制、采用什么方法及代价 | 算子/通信路径、现有实现与缺口、可验证的收益或验收指标 |

概览页可以用“模型概览、Attention、KV格式、MoE、原生量化”等短标签组织事实摘要；不要求每个标签都齐全，也不在窄结论栏强塞五段文字。最关键判断放结论栏，支撑事实紧邻结构图或对照表。部署页通常两句就能说明配置和结果。

## 自己的思考要从本页证据推出来

- 先选影响决策的事实，再解释它改变了哪段计算或哪项资源；有依据时给出优先级、适用条件和取舍。
- 模型结构变化小，可以判断适配工作集中在哪些新增路径；不要为了显得有洞察而把继承结构写成创新。
- 缓存变小，要继续看索引扫描、离散访存、量化转换或通信是否进入关键路径；没有profile时写机制推断，不写已定位性能瓶颈。
- 部署方案要解释为什么选择这个起点。显存够用、吞吐更高、成本更低是不同判断；“最优、最小、必须”各自需要比较依据。
- 不必每页强行补风险句。有重要未知项时说明它影响哪个判断、需要验证哪条路径；具体事实和可用结果仍要保留。

## 写法对照

下面只示意表达方式，不提供任何模型的默认事实或部署数值。

| 信息不足的写法 | 更有信息的写法 |
|---|---|
| “主干基本不变，关注新增模块。” | “混合注意力和MoE主干沿用基线，变化集中在全注意力层的索引与稀疏读取；适配先验证这两条路径，再检查其缓存管理。” |
| “Top-K有助于降低开销。” | “在保存全历史索引的方案中，Top-K限制主注意力的读取量，但不会删除历史索引缓存；长上下文仍需核算索引容量与扫描成本。” |
| “A3/A5需要分别配置，显存仍需验证。” | “先写本页的P/D并行组合与规模；再写请求条件、已计开销和P最大stage/D每rank占用；最后只保留会改变部署选择的判断。” |
| “进一步优化性能。” | “如果profile显示专家派发等待占主导，优先比较缩小EP域与负载均衡方案，同时计入PP空泡或额外通信代价。” |

## 数字与术语不脱离场景

1. 原生权重格式、部署重打包格式、计算dtype、KV格式分别表述。不能由路由专家的低比特格式推断共享专家或Attention的格式。
2. P写最大stage或最大rank，D写相应实例/rank；单卡、die、设备、rank、节点的口径先核实，尤其双die硬件不能直接混用“卡”。DCP复用worker，不再乘一次设备数。
3. 明确输入长度、并发、是否含OS/HCCL/工作区。参考材料中的OS固定值或HCCL数值只属于原场景，不成为新任务默认值。
4. 已确认事实、计算结果、分析判断的依据存入备注。会改变结论的前提留在正文；引用和“我如何检查”的制作说明移入备注或工作记录。

## 交付时逐页问

- 只读结论，能否知道本页最重要的事实、变化或建议？把它放到另一模型页还能原样成立的泛话，应改写。
- 结论里的比较、原因和取舍是否由本页图表或底稿支撑？事实摘要本身有用，不强行补因果。
- 是否把本页已经得到的具体结果写出来，而不是通篇“需要、关注、待验证”？
- 设备/精度/缓存/并发口径能否对上正文？若无法对上，先修正文案或场景，不能靠脚注糊过去。
- 是否仍使用大白话和准确术语，没有把制作批注或抽象口号放进PPT？

这是宿主Agent的内容审阅要求。机械校验能发现缺字段和版式问题，不能证明原因判断或结论质量。

人工修正结论后，复核是事实/口径错误、机制理解错误、条件遗漏还是表达问题，保存对应依据与修正后的判断。将可复用的分析经验纳入反馈候选；单个模型的结果和措辞不直接成为所有模型的结论。
