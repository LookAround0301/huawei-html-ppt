# PDCP 项目汇报分支（数据驱动 + 原生 PPTX 转换）

适用于：用户给 **xlsx 数据表 + 往期 PDCP 参考材料**，要求对照参考材料做项目汇报
（PDCP/TDR/结项等评审汇报）。
普通"给主题做几页技术汇报"走主流程，不进本分支。可编辑 PPT 交付见
[references/pptx-conversion.md](pptx-conversion.md)（两分支通用，默认只交 HTML）。

核心纪律（用户多轮强调）：
1. **风格照参考材料抄，不要自创**——只换内容。不加导读行、不加分组色条、
   不自创结论式标题，除非用户要求。
2. **颜色不许猜**——从参考 PPT 的 XML 实抄（见 A2）。
3. **转 PPT 必须是原生可编辑对象**——严禁整页截图贴图（见 references/pptx-conversion.md）。

---

## A. 数据与参考材料处理

1. **二进制材料解析**：PPTX/XLSX 用 python zipfile/openpyxl 读。
   控制台是 GBK，直接 print 中文必乱码——**一律写入 UTF-8 dump 文件再用 Read 读**。
2. **样式实抄方法**：
   - 列宽：参考页 `<a:gridCol w="EMU">` → 换算百分比照抄到 HTML `th width`。
   - 颜色：`schemeClr` 需解析主题 clrScheme（tx1/tx2/bg1/bg2…），带
     `lumMod/tint` 子元素时换算（如 tx2 lumMod 95% = `#F2F2F2`）。
     `solidFill` 出现在 `<a:ln*>` 里是边框色，不是填充——取 tcPr 尾部的填充。
   - 模板默认表格样式"中度样式2-强调1"：表头 `#F2F2F2` 灰底 + `#1D1D1A` 粗体，
     表体全白、无斑马纹，边框 tx1 近黑 0.5pt。
3. **对照渲染**：拿不准参考页长什么样时，用 PowerPoint COM 导出 PNG 看真图，
   不要凭 dump 文本想象（导出前把文件拷成 ASCII 路径名，中文路径 COM 会 E_FAIL）：
   ```powershell
   $pp = New-Object -ComObject PowerPoint.Application
   $pres = $pp.Presentations.Open("$env:TEMP\ref.pptx", $true, $false, $false)
   $pres.Slides.Item(45).Export("$env:TEMP\s45.png", 'PNG', 1280, 720)
   ```

## B. PDCP 标准页序（对照参考 deck，按需裁剪）

| 章 | 页 | 要点 |
|---|---|---|
| 组合概述 | 封面→目录→**变更说明** | 变更表 5 列：变更说明/原因/影响/责任人/决策建议；前缀（新增/裁剪/删除技术点：）蓝粗斜体，【技术点名】红粗，后两列蓝粗斜体；底部"说明：…"注释 |
| | **专题清单**（每专题一页） | 12 列：序号/名称/代际/描述/交付形式/工作量/专家/团队/完成/落地/版本/专利论文；列宽照抄参考 gridCol；组内行数选 tight(10-12行)/roomy(≤5行) |
| 项目计划 | **专利与论文** | 黑框卡片（专利）+ 红框卡片（论文），验收标准脚注 |
| | **项目迁移策略** | 12 列含"技术点"组列（rowspan 合并，按专题分组）；页数按 10 行/页拆 |
| | **关键里程碑** | 琥珀时间轴 `#FFCC66` + 红虚线 `#C20041` + 三阶段带 + 蓝渐变箭头(#0000FF→#FFFF35) + 青椭圆日期(#30B5C5) + 绿色 TDR 日期牌(#61B230)，实际(红)/建议(灰)标注；左下蓝斜体注释+裁剪规则小表，右下双列日期表 |
| | **相关技术点关键里程碑&周边依赖** | 三带式甘特：技术项目群里程碑带（蓝牌+蓝斜体日期+贯穿虚线）/ 技术点完成行（青三角+日期）/ 产品落地带（黑三角+组件版本虚线框）；红虚线连"技术点完成→承接落地" |
| | **费用及分摊** | 四象限：一预算整体信息（嵌套科目表：研发费用/直接费用 rowspan，增量数字红）、二物料说明（蓝字）、三人力来源、四费用来源（确认人蓝斜体） |
| 决策申请 | （按需）决策建议 | 红标签块三段：里程碑/项目变更/预算分摊 |

- **裁剪技术点**：不进清单/迁移表（删除后全册序号连续重排），但变更记录
  保留在"变更说明"页。
- 章节过渡目录页：每章前重复目录页并切换高亮；删章时连其目录页一起删，
  目录重编号。

## C. 通用规则

- 页码 `Page X/Y` 全册唯一；任何插页/删页/拆页后全册重排（含分母）。
- 数据一律从 xlsx/HTML 解析注入，**禁止手抄转录**（容易抄错数字）。
- 迭代闭环：每页生成后 headless Chrome 截图逐页裁开检查（主流程配方），
  用户的反馈优先级：格式一致性 > 内容完整性 > 美化。

## D. HTML → 原生 PPTX 转换

用户明确要求交付可编辑 PPT 时，按
[references/pptx-conversion.md](pptx-conversion.md) 执行（两个分支通用：
原生文本框/表格/形状，禁止截图贴图；数据从交付 HTML 解析注入）。
PDCP 特有注意点：依赖甘特图/时间轴的形状重建坐标函数在本分支页面最复杂，
严格按转换文档的"坐标只换算一次"和 rowspan/merge 坑位执行。
