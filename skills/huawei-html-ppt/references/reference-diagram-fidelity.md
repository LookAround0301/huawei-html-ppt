# 参考图的结构保真

用户给出的完整结构图优先于通用图元模板。先读原图本身，不仅提取标题和颜色。

## 重绘前的对应表

- 主干：输入到输出的方向、重复块的范围与次数、例外层。
- 分支：每条路径从哪里分出，在哪里汇入，是否并行、共享或条件分派。
- 回路：门控、残差、状态更新的起点、终点和运算符。
- 存储：什么内容写入、由哪个算子读取，是否完整历史、局部切片或固定状态。
- 若使用关联视图，明确其对应模块与层次。

现成图已经表达清楚时直接本地复用。技术项目必须先查用户材料、对应版本仓库文档和官方论文；不能仅为统一配色、套用组件或可编辑性重绘。确需改变技术内容、原图不适用或不可读时，才按已核对的拓扑改绘，底稿记录原因和改动。只有输入数据和技术结构确实不同才改变拓扑。不要以简化为名把完整路径拆成互不连接的小卡片。

## 页面取舍

优先给图足够面积，再压缩旁边的重复解释。根据数据流方向、结构复杂度和页面空间选择布局。不在同页额外塞无关参数表。保持文字可读；必要时拆分总览和细节，而不是删掉关键支路。

输入与输出直接用英文文字，矩阵只用于解释真实布局；缓存用简洁矩形，不画圆饼状图元。

## 颜色

新绘技术图可用少量低饱和填充分区，但文字、边注、尺寸和图例统一黑灰红。黑色用于正常标签，灰色用于次要说明，红色用于关键新增/变更；不使用绿紫橙等多色文字。图线以灰色为主，关键控制/放大线可红色。原图优先选用英文版；只有中文版时，在本地副本中准确翻译图内文字并保留原始文件，不改技术含义和拓扑。新增标注也使用英文并遵守上述配色。来源仍放隐藏备注。

## 交付检查

原图复用核对版本、内容、清晰度、比例、图例和关键分支完整性。重绘时将原图和重绘图并排逐项核对主干、分支、回路、缓存及实际使用的关联视图，确认继承和新增部分；不能只检查文本没有溢出就宣布完成。新绘 SVG 与 draw.io 从同一几何数据输出；原图只嵌入原资源，不伪称可编辑图源。保留原参考文件不修改、不上传。
